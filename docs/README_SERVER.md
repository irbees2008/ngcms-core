## Проблема

При открытии `index.html` напрямую из файловой системы (через `file://` протокол) браузер может блокировать загрузку .md файлов из-за политики безопасности CORS.

## Решение

### Вариант 1: Запуск через встроенный PHP сервер (РЕКОМЕНДУЕТСЯ)

1. **Двойной клик по `START_SERVER.bat`**
   - Скрипт автоматически запустит сервер на http://localhost:8080

2. **Или вручную через командную строку:**

   ```bash
   cd c:\OSPanel\home\it\docs
   php -S localhost:8080
   ```

3. Откройте в браузере: **http://localhost:8080**

### Вариант 2: Использование OSPanel

Если OSPanel запущен, документация доступна по адресам:

- **http://localhost/docs/**
- **http://it/docs/** (если настроен виртуальный хост)

### Вариант 3: Использование другого веб-сервера

Любой другой локальный веб-сервер (Apache, Nginx, Node.js http-server и т.д.) также подойдет.

## Технические детали

XMLHttpRequest поддерживает:

- ✅ `file://` протокол (локальные файлы)
- ✅ `http://` протокол (веб-сервер)
- ✅ `https://` протокол (защищенный веб-сервер)

Поэтому документация теперь работает в обоих режимах!
