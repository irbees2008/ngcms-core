# Пошаговый план интеграции SQLite в NGCMS

Текущее состояние: отдельная схема `engine/trash/tables.sqlite.sql` подключена
к экспериментальному пути установки. Поддержаны подключение SQLite, создание
схемы, базовые операции установки таблиц плагинов и часть MySQL-совместимости.
Точечные тесты проходят на PHP 8.2 и 8.5. Полная совместимость CMS, плагинов,
резервного копирования и обновления схемы ещё не подтверждена.

Чекбоксы ниже отмечают уже реализованные части. Отметка отдельного этапа не
означает полной совместимости SQLite: неотмеченные проверки и ограничения
перечислены в плане и в [`sqlite-integration.md`](./sqlite-integration.md).

## Риски и смягчающие меры

| Риск | Вероятность | Влияние | Решение |
|------|-------------|--------|---------|
| Несовместимость SQL | Средняя | Высокое | Создать адаптер SQL, обширное тестирование |
| Проблемы с блокировками | Средняя | Среднее | Использовать WAL mode, документировать ограничения |
| Регрессия MySQL | Низкая | Критическое | Развести код на ветки, интенсивное тестирование |
| Проблемы производительности | Низкая | Среднее | Оптимизация индексов, PRAGMA параметры |
| Недопонимание пользователями | Средняя | Среднее | Подробная документация, четкие рекомендации |
